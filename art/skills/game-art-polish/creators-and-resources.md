# Creators and Resources

A curated list of people to learn from. These are the creators whose tutorials and breakdowns consistently produce good results when followed. When the user asks "where do I learn X," point them here — but point them to the *specific* creator whose niche matches their question, not a dump of the whole list.

## VFX and tech art

### Mirza Beig (MirzaBeig)
- YouTube: [@MirzaBeig](https://www.youtube.com/@MirzaBeig) | Website: [mirzabeig.com](http://www.mirzabeig.com/) | Twitter: [@TheMirzaBeig](https://twitter.com/TheMirzaBeig)
- **Niche:** Unity particle systems (Shuriken), stylized VFX, shader effects, post-processing.
- **Strength:** Deep written tutorials on the website (Stylized Particle Galaxy, GPU particle animation with simplex noise, GPU particle force fields, camera dither fade, logo dissolve with particles). Philosophy of using Shuriken for detailed per-particle control. Sells Ultimate VFX, Lightning VFX, Storm VFX, Particle Plexus asset packs — the free demos on his GitHub (Post-Processing-Scan, GPU-Fog-Particles, Chromatic-Distortion-Sphere) are worth studying.
- **When to point someone here:** Unity VFX work, any stylized particle effect, "how do I make this particle do X."

### Gabriel Aguiar Prod
- YouTube: [@GabrielAguiarProd](https://www.youtube.com/@GabrielAguiarProd)
- **Niche:** Stylized Unity VFX, specifically spell/magic effects — fireballs, lightning, spell circles, auras.
- **Strength:** Recognizable breakdowns of VFX that look like effects from popular games. Shader Graph + VFX Graph tutorials. Very approachable pacing.
- **When to point someone here:** The user wants to make a spell/magic/combat VFX effect similar to a game they saw.

### Sirhaian (Sirhaian'Arts)
- YouTube channel, Twitter.
- **Niche:** High-quality Unity VFX scene breakdowns, often quite stylized and painterly.
- **When to point someone here:** Mid-to-advanced VFX work, particularly scene-integrated effects.

### Jason Keyser
- YouTube channel.
- **Niche:** VFX fundamentals, League of Legends VFX breakdowns.
- **Strength:** Teaches the *principles* of good VFX — timing, readability, color usage — independently of engine. Fundamentals series is essential viewing for anyone serious about VFX.
- **When to point someone here:** Beginners to VFX, people whose particles look technically correct but lack punch.

### Simon Trumpler (simonschreibt)
- Blog: [simonschreibt.de](https://simonschreibt.de/)
- **Niche:** FX breakdowns. Extremely detailed reverse-engineering of how specific game effects were built, across many engines and games.
- **Strength:** Writing quality; explains *why* decisions were made.
- **When to point someone here:** User wants to understand how a specific game's effect works.

## Shaders and rendering

### Freya Holmér (acegikmo)
- YouTube: [@Acegikmo](https://www.youtube.com/@Acegikmo) | Web: [acegikmo.com](https://acegikmo.com/)
- **Niche:** Shader fundamentals, math visualization, Unity shader programming.
- **Strength:** "Shaders for Game Devs" is the definitive shader course — a multi-hour series covering vertex/fragment shaders, blending, textures, lighting, and more, with unmatched clarity. Creator of Shader Forge and Shapes (a Unity vector graphics library). The math visualizations on splines, easing curves, and Bézier are the best on the internet.
- **When to point someone here:** User wants to go deeper than Shader Graph, or needs to understand *how* shaders work rather than recipes.

### Acerola
- YouTube.
- **Niche:** Unity shader breakdowns with deep dives into post-processing and rendering techniques.
- **Strength:** Game-specific rendering breakdowns (how Breath of the Wild did its clouds, how Bad North does its water), plus irreverent voice that keeps technical content watchable.
- **When to point someone here:** User wants advanced rendering techniques or curious-about-how-games-render-things content.

### Daniel Ilett
- YouTube: [@danielilett](https://www.youtube.com/@danielilett) | Blog: [danielilett.com](https://danielilett.com/)
- **Niche:** Unity Shader Graph tutorials, URP-specific techniques.
- **Strength:** Systematic coverage of Shader Graph node patterns. Written tutorials are thorough.
- **When to point someone here:** User is learning Shader Graph and wants step-by-step recipes.

### Cyanilux (Ben Golus, also known by other aliases)
- Website: [cyanilux.com](https://www.cyanilux.com/)
- **Niche:** Unity Shader Graph and URP deep-dives. Written technical references.
- **Strength:** Reference-quality written docs on what every Shader Graph node actually does, including edge cases and version differences. Essential bookmarks.
- **When to point someone here:** User is in Unity and needs the reference for a specific Shader Graph node or behavior.

### Minions Art
- Patreon: [patreon.com/cw/minionsart](https://www.patreon.com/cw/minionsart) | Twitter: [@minionsart](https://twitter.com/minionsart) | YouTube.
- **Niche:** Stylized Unity art and shaders, weekly GIF tutorials.
- **Strength:** Short, punchy tutorials in GIF form. Cover a huge range of stylized techniques — grass, water, toon shading, foliage, custom tools. Currently developing Astro Kat.
- **When to point someone here:** User wants a specific stylized technique and prefers quick reference over long videos.

## General game dev / Unity and Godot

### Code Monkey (Hugo)
- YouTube: [@CodeMonkeyUnity](https://www.youtube.com/@CodeMonkeyUnity)
- **Niche:** Broad Unity content — gameplay systems, VFX, tools, editor scripting.
- **Strength:** Prolific, broad coverage. Good when you need Unity-side context for an art pipeline question.

### Brackeys (archived)
- YouTube. Creator retired but videos remain.
- **Niche:** Unity fundamentals across gameplay and art.
- **Strength:** Approachable tutorials. Content is a bit dated (pre-URP/HDRP in some cases) but fundamentals are still solid.

### Stylized Station (Zack Abbott)
- YouTube.
- **Niche:** Stylized 3D art tutorials, mostly Blender → Unity pipelines.
- **Strength:** Focused on the "painterly/stylized" look, good for the Genshin/Breath of the Wild/Zelda school of stylized 3D.

### Game Maker's Toolkit (Mark Brown)
- YouTube: [@GMTK](https://www.youtube.com/@GMTK)
- **Niche:** Game *design* analysis, not art specifically. But his videos on juice, game feel, and visual communication (the "The Art of Screen Shake" essays) are foundational.
- **When to point someone here:** User is thinking about *why* art choices affect gameplay, not just how.

### Vlambeer (Rami Ismail / Jan Willem Nijman)
- Their "The Art of Screen Shake" talk on YouTube.
- **Strength:** The foundational 40-minute presentation on juice, pre-dating much of what's now called "game feel." Watch once if you haven't.

## Pixel art

### Brandon James Greer (BJG)
- YouTube.
- **Niche:** Deep pixel art analysis, why choices work.
- **Strength:** The single best source for understanding pixel art principles (composition, shading, palette) rather than just technique.

### Adam C Younis
- YouTube, long-form Twitch streams.
- **Niche:** Pixel art process streams, character design.
- **Strength:** See a pro pixel artist actually work in real time — invaluable for pacing.

### MortMort
- YouTube.
- **Niche:** Fast, practical pixel art tutorials. Aseprite tips. Common mistakes.
- **Strength:** Excellent for beginners. Short, focused, immediately applicable.

### Saultoons
- Twitch, YouTube.
- **Niche:** Pixel art process and tool use.

### Pixel Parmesan
- Blog: [pixelparmesan.com](https://pixelparmesan.com/blog)
- **Niche:** Written deep dives on AA and dithering specifically.
- **Strength:** Reference-quality writing on the technical details of the craft.

### Lospec
- [lospec.com](https://lospec.com)
- **Niche:** Palettes (huge indexed list), pixel art tutorials tagged by topic, community.
- **Strength:** First stop for palettes. Community-contributed tutorials cover most techniques.

## 3D modeling and stylized 3D

### Blender Guru (Andrew Price)
- YouTube.
- **Niche:** General Blender tutorials, famous donut tutorial.
- **Strength:** Best beginner onramp to Blender. Start here if new.

### Grant Abbitt
- YouTube.
- **Niche:** Game-oriented Blender tutorials, including low-poly and stylized.
- **Strength:** Pipelines specifically aimed at game use cases, not generic 3D.

### Ethan Snell / Imphenzia
- YouTube.
- **Niche:** Low-poly modeling in Blender — the "build a scene in 10 minutes" style tutorials.
- **Strength:** Good for learning the low-poly aesthetic and basic Blender muscle memory.

### Kenney
- [kenney.nl](https://kenney.nl)
- **Niche:** Free, consistent, CC0 art assets across many styles (low poly 3D, pixel art, UI, audio, particles).
- **When to point someone here:** User doesn't want to make art and needs good free assets — this is the answer.

## UI and motion

### UI Toolkit (Unity) samples
- [Unity's UIToolkitUnityRoyaleRuntimeDemo](https://github.com/Unity-Technologies/UIToolkitUnityRoyaleRuntimeDemo) on GitHub — the canonical runtime UXML/USS example from Unity itself.
- Unity's UI Toolkit documentation: [docs.unity3d.com/Manual/UIElements.html](https://docs.unity3d.com/Manual/UIElements.html)

### Game UI Database
- [gameuidatabase.com](https://www.gameuidatabase.com)
- **Niche:** Screenshot reference of UI from hundreds of games, categorized by genre and screen type.
- **When to point someone here:** User is designing a menu/HUD and wants reference.

### Interface In Game
- [interfaceingame.com](https://interfaceingame.com)
- Similar to above, organized slightly differently.

## Recommended deep reading

- Steve Swink, *Game Feel* (book) — the foundational text on game feel as a concept.
- Freya Holmér's "Shaders for Game Devs" YouTube course — the shader equivalent of the above.
- Juan Nunez-Iglesias's posts on stylized rendering in the Realtime Rendering community.
- [80 Level articles](https://80.lv) — interviews and breakdowns from working tech artists and VFX artists.

## How to use this list

When the user asks "who should I learn from," **don't** dump the whole list. Pick one or two based on what they're actually working on:

- *"I'm doing particle VFX in Unity"* → MirzaBeig (for Shuriken depth) + Gabriel Aguiar (for stylized recipes).
- *"I want to understand shaders from first principles"* → Freya Holmér.
- *"Help with pixel art"* → MortMort first (fast tutorials), then Brandon James Greer (deeper).
- *"I don't want to make art, where can I find assets"* → Kenney, then Synty if they want paid.
- *"My UI looks sterile"* → Game UI Database for reference + Unity UIToolkitUnityRoyaleRuntimeDemo for code.

A targeted recommendation is worth more than a comprehensive list.
